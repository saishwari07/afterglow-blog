# Afterglow

A futuristic multi-page blog built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## Pages
- `index.html` home with hero and latest essays
- `journal.html` all essays with topic filters and search
- `archive.html` sortable table of every essay
- `authors.html` table of writers
- `about.html` about page and publishing schedule

## Features
Animated constellation background, 3D tilting cards, essay reader pop-up, light and dark theme, scroll progress bar, responsive layout.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new repository and upload all files from this folder.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Edit the content
Essays and writers are listed at the top of `app.js`. Change the text there and every page updates.
